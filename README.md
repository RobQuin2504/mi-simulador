🛒 Simulador: Validador de Stock

Pequeño simulador desarrollado en JavaScript que permite validar la cantidad de productos que un usuario desea comprar y calcular el total de la compra.

Además, el proyecto incluye diferentes operaciones con arreglos, como agregar, eliminar, buscar y mostrar productos.

📌 Funcionalidades
Validar que la cantidad solicitada esté dentro del stock disponible.
Calcular el total de una compra.
Mostrar un resumen de la compra.
Agregar productos al final de un arreglo.
Agregar productos al inicio de un arreglo.
Buscar productos dentro del arreglo.
Eliminar el último producto del arreglo.
Mostrar la lista de productos disponibles.

🛠️ Tecnologías
JavaScript
prompt() para recibir datos del usuario.
alert() para mostrar mensajes.
console.log() para mostrar información en la consola.

📂 Estructura

El simulador trabaja principalmente con:

Variables: precio unitario y stock disponible.
Arreglos: lista de productos.
Funciones: validación, cálculo, búsqueda y manipulación de productos.
Bucles: validación de la cantidad ingresada.
Métodos de arreglos: push(), unshift(), pop() e indexOf().

▶️ Uso

Al ejecutar el programa:

Se solicita al usuario la cantidad de unidades que desea comprar.
Se valida que la cantidad esté entre 1 y el stock disponible.
Se calcula el total de la compra.
Se muestra un resumen de la compra.
Se realizan diferentes operaciones sobre el arreglo de productos.

🎯 Objetivo

Este proyecto tiene como objetivo practicar conceptos fundamentales de JavaScript, especialmente:

Variables y constantes.
Funciones.
Condicionales.
Bucles while.
Arreglos.
Métodos para manipular arreglos.
Entrada y salida de datos.
Separación de funcionalidades mediante funciones.
